## 피드백 요약

`내 QR`의 전체·매장별 공유 버튼을 눌렀을 때 복사 성공 여부가 화면에서 충분히 드러나지 않는다. 성공 문구를 일시적 확인 모달로 표시하고 눌린 버튼에도 즉각적인 클릭 animation을 제공한다.

## 상세 피드백

| 위치 | 내용 | 기대 결과 |
|---|---|---|
| `app/page.tsx` 공유 성공 상태 | 기존 알림이 스크롤 위치에서 눈에 띄지 않음 | `공유 링크가 복사되었습니다.`가 현재 viewport의 확인 모달로 표시됨 |
| `app/globals.css` 공유 버튼 | 클릭 후 시각적 반응이 부족함 | 전체·매장별 공유 버튼이 짧게 눌리고 복귀하는 animation을 제공함 |

## 우선순위

- must-fix: 성공 확인 모달의 정확한 문구와 viewport 기준 표시
- must-fix: 활성 공유 버튼 클릭 시 일시적 눌림 animation
- should-fix: 연속 클릭 timer 경합 방지와 reduced-motion 대체
- note: QR payload와 Clipboard 복사 방식은 변경하지 않음

## 반영 기준

- 전체·매장별 공유 성공 시 `공유 링크가 복사되었습니다.`가 약 2~3초 동안 표시된다.
- 클릭한 활성 버튼에만 짧은 피드백 animation이 적용되고 자동으로 원상 복귀한다.
- 성공은 `role="status"`, 실패는 `role="alert"`로 안내한다.
- `prefers-reduced-motion` 환경에서 spatial animation 없이 동일한 상태 정보가 전달된다.
- `npm test`, `npm run lint`, `npm run build`와 실제 브라우저 클릭 시나리오가 통과한다.

## 후속 확인

- 모바일 viewport에서 페이지를 스크롤한 상태에도 확인 모달이 화면 중앙에 나타나는지 확인한다.
- 같은 공유 버튼을 연속으로 눌러도 최신 알림이 약속된 시간 동안 유지되는지 확인한다.
