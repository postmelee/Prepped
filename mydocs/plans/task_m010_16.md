# Task #16 수행계획서 — PWA 하단 고정 UI 회귀 수정 및 QR 카드 액션 정리

GitHub Issue: [#16](https://github.com/postmelee/Prepped/issues/16)
마일스톤: M010

## 목적

긴 카탈로그 목록에서도 선택 메뉴 바텀시트와 PWA 하단 메뉴바를 현재 viewport 하단에 안정적으로 표시한다. `내 QR` 매장 카드에서는 포함 토글을 제거하고 공유 버튼을 오른쪽에 배치해 현재 사용자 흐름에 맞게 액션을 단순화한다.

## 배경

배포된 PWA에서 메뉴 목록이 길어지면서 `.phone-app`의 문서 높이가 viewport보다 커졌다. 현재 `.bottom-nav`와 `.sheet-backdrop`은 `.phone-app`을 기준으로 한 `position: absolute`이므로 화면 하단이 아니라 긴 문서의 마지막에 배치된다. 또한 `내 QR` 매장 카드에는 매장 편집·공유·QR 포함 토글이 동시에 노출되어 사용자가 요청한 단순한 공유 흐름과 맞지 않는다.

## 범위

### 포함

- 선택 메뉴 backdrop과 바텀시트를 viewport 기준 고정 레이어로 변경
- 바텀시트 최대 높이, 내부 스크롤, safe-area 및 데스크톱 PWA 셸 경계 유지
- 공통 PWA 하단 메뉴바를 viewport 하단에 고정하고 기존 본문 하단 여백 유지
- `내 QR` 매장 카드의 포함 토글 제거와 공유 버튼 우측 정렬
- 메뉴 유무에 따른 공유 버튼 활성·비활성 상태 유지
- 정적 렌더링 계약, 모바일 빌드와 브라우저 회귀 검증

### 제외

- 카탈로그 데이터와 Catalog API 계약 변경
- QR payload의 매장별 `enabled` 직렬화 정책 변경
- `내 설정` 화면의 QR 사용 상태 토글 변경
- 키오스크 QR 파싱·메뉴 매칭 및 결제 데모 변경
- AWS·Sites 배포 설정 변경과 공개 재배포

## 설계 방향

- `.bottom-nav`와 `.sheet-backdrop`은 문서 높이에 종속된 absolute 배치에서 viewport 기준 fixed 배치로 전환한다.
- 고정 레이어는 `left: 50%`, `transform: translateX(-50%)`, `width: min(100%, 480px)` 패턴으로 중앙 PWA 셸과 정렬한다. 데스크톱 breakpoint에서는 기존 24px 외곽 여백과 둥근 모서리를 유지한다.
- 바텀시트는 기존 `max-height`와 `overflow-y: auto`를 유지·보강해 콘텐츠가 길 때 시트 내부만 스크롤되도록 한다. fixed backdrop의 z-index는 하단 메뉴바보다 높게 유지한다.
- `.screen`의 기존 하단 padding을 고정 메뉴바 높이의 콘텐츠 가림 방지 여백으로 유지하고, 동적 viewport와 safe-area를 함께 고려한다.
- `내 QR` 카드에서는 `page.tsx`의 `role="switch"` 버튼만 제거한다. 저장 설정의 `enabled` 값과 `StoreSettings`의 토글은 그대로 두어 QR 직렬화 계약과 설정 화면 기능을 바꾸지 않는다.
- 공유 버튼은 카드 grid의 오른쪽 열을 사용하고 두 행을 차지하도록 정렬한다. 메뉴가 없는 카드의 disabled 동작은 유지한다.

- `git status --short`가 PR 준비 전 빈 출력이다.
- `git diff --check`가 경고 없이 통과한다.

## 리스크

- **iOS 동적 viewport와 safe-area 차이**: `svh` 기반 기존 fallback을 유지하면서 fixed inset과 `env(safe-area-inset-bottom)`을 조합해 홈 인디케이터 영역을 보존한다.
- **데스크톱 PWA 셸 정렬**: viewport 전체 fixed 요소가 480px 앱 영역을 벗어나지 않도록 동일한 중앙 정렬·너비 규칙을 메뉴바와 backdrop에 적용한다.
- **CSS transform 충돌**: fixed 요소의 중앙 정렬 transform과 바텀시트 등장 animation을 서로 다른 요소에 두어 animation이 레이어 정렬을 덮어쓰지 않게 한다.
- **QR 활성 상태 계약 회귀**: QR 화면의 토글 UI만 제거하고 저장 모델·직렬화·설정 화면 토글은 변경하지 않으며 기존 모바일 테스트로 확인한다.
