## 잔여 위험과 후속 작업

### 잔여 위험

- 카메라 스캔 성공률은 심사 기기의 권한·조명·초점에 의존한다. 샘플 QR과 수동 입력이 공식 대체 절차다.
- GitHub Actions check가 저장소에 등록되지 않았을 수 있어 PR 게시 후 원격 상태를 별도로 확인해야 한다.
- `npm ci`는 기존 의존성에서 17개 audit 취약점 후보(낮음 2, 높음 15)를 보고했다. 문서 task에서 수정하지 않았다.

### 후속 작업 후보

- 별도 의존성 보안 점검 이슈에서 audit 결과의 실제 영향과 안전한 업데이트 범위를 평가한다.
- 해커톤 제출 양식이 영상이나 스크린샷을 요구하면 별도 사용자 승인 task로 README 미디어를 추가한다.
