## 작업 요약

- 대상 이슈: #4

- 단계 수: 3
- 작업 목적: 모바일 PWA에서 매장별 저장 메뉴를 확인·수정하는 `내 설정 메뉴` 화면과 하단 탐색을 추가한다.

사용자는 이제 `내 QR`, `메뉴 만들기`, `내 설정`을 하단에서 바로 오갈 수 있다. 설정 화면은 맥도날드의 저장 메뉴·가격·합계·QR 포함 상태를 보여주고 해당 매장이 선택된 빈 편집 초안으로 수정을 연결한다. 편집 화면을 나갈 때는 안전한 기본 행동이 `저장하지 않음`인 확인 모달이 기존 메뉴를 보호한다. 서브웨이는 실제 데이터가 없는 상태를 준비 중 카드로 명확히 보여준다.

## 잔여 위험과 후속 작업

### 잔여 위험

- 현재 공개 URL은 version 2라 새 `내 설정 메뉴` 화면이 아직 반영되지 않았다. 저장된 version 5를 게시하려면 `기존 public 접근으로 version 5 게시`라는 명시 승인이 필요하다.
- 메뉴 설정은 브라우저 `localStorage`에만 있어 다른 기기와 동기화되지 않는다.
- 서브웨이는 실제 메뉴 데이터 없이 준비 중 상태만 제공한다.
- 실제 휴대폰 QR과 노트북 카메라의 하드웨어 E2E는 사용자 기기에서 확인해야 한다.
- 선행 PR #2가 열려 있으므로 이번 PR은 `publish/task1` 대상 스택 PR로 먼저 생성한다. PR #2 병합 후 base를 `devel`로 바꿔야 한다.

### 후속 작업 후보

- 명시적 공개 승인 후 Sites version 5 프로덕션 게시와 두 경로 확인
- PR #2 병합 후 PR #4의 base를 `devel`로 변경
- 매장별 저장 schema 확장과 서브웨이 실데이터/API 연동
- 기기 간 동기화를 위한 계정·백엔드 저장 설계
- 실물 휴대폰·노트북 카메라 E2E와 브라우저 호환성 검증
